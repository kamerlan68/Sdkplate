# ExtraTools — Android/Kotlin

## Сборка
1. Распакуй архив.
2. Открой папку `ExtraTools` в Android Studio.
3. Дождись Gradle Sync (нужен Android SDK 35 и JDK 17).
4. Выбери Build → Build Bundle(s) / APK(s) → Build APK(s).

## Реализовано
- Главный экран ExtraTools в строгом серо-чёрно-белом стиле.
- Файловый менеджер через Android Storage Access Framework: выбор папки, просмотр директорий, поиск, сортировка, создание папок, переименование, удаление, свойства и SHA-256.
- APK Extractor: список приложений, доступных PackageManager, копирование APK в выбранную папку.
- APK Explorer: просмотр ZIP/APK структуры, переход по папкам, текстовый просмотр небольших XML/TXT/JSON/YAML/CFG файлов, информация для бинарных файлов, извлечение содержимого в выбранную папку.
- File Scanner: локальные эвристические проверки структуры архива и имён записей.
- Русский / English / 中文, светлая и тёмная темы с сохранением настроек.

## Ограничения Android
- Доступ к хранилищу выдаётся пользователем через системный выбор папки. Приложение не получает автоматически доступ ко всем каталогам.
- Android/data, Android/obb и другие защищённые места могут быть недоступны из-за ограничений версии Android и производителя.
- Список приложений зависит от системной политики видимости пакетов. В манифесте объявлен QUERY_ALL_PACKAGES; распространение через Google Play может потребовать обоснования.
- Сканер — не антивирус. Он не расшифровывает бинарный AndroidManifest.xml и не доказывает безопасность APK.
- Для чтения больших файлов предусмотрены ограничения предпросмотра; DEX и SO показываются как бинарные файлы с размером и SHA-256, не как декомпилированный исходный код.
- В этой стартовой версии нет сетевых дисков, плагинов, терминала, VIP, корзины, облака или удалённого управления — они не запрашивались.
